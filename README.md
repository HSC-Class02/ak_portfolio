1. 소개 (About Me)

## 자격 표기 원칙

생활스포츠지도사 2급은 미취득이므로 공개용 포트폴리오에서는 보유 자격으로 표시하지 않습니다.

## 배포

GitHub Settings → Pages → Deploy from a branch → main / root 를 선택해 배포합니다.
